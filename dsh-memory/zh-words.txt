# dsh-memory 中文词典（v3.12）
# 一行一词，2–3 字为主。用途：把 bigram 切分换成「词」切分，治跨词边界假命中（_review-a.md A6）。
# 口径：只收真词，同词根不同词性各收一条都行，但**不要收跨词拼接产物**（如「好看的电」「件之后」）。
# 增词原则：真实记忆库里反复出现的名词/动词 + 插件领域词；宁少勿滥，未知词走 bigram 兜底。
# 来源：82 条真实记忆 + 四套基准语料做新词发现（频次/左右熵/内聚度），再逐条人工筛选。
